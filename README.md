# Agenda de Contatos

Projeto desenvolvido em Python para gerenciar contatos diretamente pelo terminal.

## Funcionalidades

- Adicionar contatos
- Listar contatos
- Editar contatos
- Favoritar contatos
- Desfavoritar contatos
- Listar contatos favoritos
- Deletar contatos
- Validação de email
- Validação de telefone
- Tratamento de exceções personalizadas
